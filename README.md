# משחק האותיות א-ב 🎒

מסע קסום עם לוּלָה הַמְּגַלָּה ללימוד אותיות ומילים, לגן חובה ולכיתה א.

▶ לשחק עכשיו: https://yontanbe.github.io/mishak-haotiyot/

רוח שובבה העיפה את כל האותיות מהתיק של לולה. יוצאים איתה דרך יער, חווה, חוף, מדבר, הרים, טירה בעננים ועמק הסופיות,
פוגשים 27 חברים, ובכל תחנה מחזירים אות אחת הביתה דרך 19 שלבים: סיפור, הכרות עם האות, הברות, ציור באצבע,
שש מילים חדשות, בועות, בחירת תמונות, האזנה, מחבואים, זיכרון, אות חסרה, כן או לא, מסיבת מילים וחגיגה.

- בכניסה בוחרים עברית או English
- עולם האותיות: 22 אותיות ו-5 אותיות סופיות, כל הטקסטים עם ניקוד מלא
- עולם הצבעים: 10 צבעים, ערבוב צבעים, וטיפות צבע שמחזירות את הצבע לעולם אפור
- גדול וקטן, איפה זה? (מילות מקום), ומסע החיות עם שיר
- מספרים עד 10, חיבור וחיסור עם סיפורי צפורים, פינת הסיפורים (4 סיפורים מקוריים על ילדים וחיות שמתגברים על קושי), ופינת מה זה שיר (חרוזים, הברות ו-4 שירים)
- צד English לדוברי עברית: 9 נושאים (Hello, צבעים, מספרים, גוף, משפחה, חיות, אוכל, רגשות, פעולות) ו-ABC עם 26 אותיות, עם יוגי הינשוף
- קריינות בעברית שנוצרה עם Gemini TTS לפי הניקוד (1,322 קטעים), עם גיבוי לדיבור של הדפדפן
- לולה וכל 27 החברים בסגנון סרט אנימציה תלת ממדי (Gemini Nano Banana Pro), עם אנימציה של נשימה, הליכה, דיבור וקפיצה
- מסך בית, קטעי מעבר שבהם לולה הולכת בין התחנות, והפסקות שבהן היא מדברת ישירות אל הילד
- עובד בטלפון, בטאבלט ובמחשב, בלי התקנה ובלי שרת

## התקדמות וציון
- ההתקדמות נשמרת אוטומטית בדפדפן: אילו אותיות הושלמו, כוכבים, תשובות נכונות וטעויות, וזמן משחק.
- הילד רואה במסך הבית את הכוכבים שלו (עד 81), פס התקדמות של 27 אותיות, ודרגה שעולה עם הכוכבים:
  🌱 מתחילים את המסע, 🔎 בלשי אותיות, 🧭 מגלי אותיות, 🦸 גיבורי האותיות, 🏆 אלופי האותיות, 🌟 כוכבי האותיות.
- בכל אות: 3 כוכבים עד 2 טעויות, 2 כוכבים עד 6 טעויות, כוכב אחד מעבר לזה. אפשר לשחק אות שוב, ונשמרת התוצאה הטובה ביותר.
- דוח הורים (⚙️ במסך הבית, אחרי תרגיל חשבון קטן): אותיות שהושלמו, כוכבים, אחוז דיוק, זמן משחק, מפה צבעונית של כל 27 האותיות,
  אילו אותיות כדאי לתרגל ובאילו סוגי משחקים יש הכי הרבה טעויות.
- גיבוי והעברה למכשיר אחר: בדוח ההורים יש קוד גיבוי. מעתיקים אותו ומדביקים בפינת ההורים במכשיר השני.

## להעתיק את המשחק לחשבון שלכם
יש שתי דרכים:
1. כפתור Use this template בראש הדף בגיטהאב (או Fork). נוצר עותק שלם בחשבון שלכם.
2. או Code ← Download ZIP כדי להוריד את כל הקבצים.

## לפרסם ב-GitHub Pages
1. בעותק שלכם: Settings ← Pages ← Source: GitHub Actions.
2. כל דחיפה ל-main מפרסמת את המשחק אוטומטית (קובץ ‎.github/workflows/pages.yml).
3. הכתובת תהיה https://<שם-המשתמש>.github.io/<שם-הריפו>/

## להריץ ולבנות במחשב
צריך Node.js 18 ומעלה ו-Python 3.
```
git clone https://github.com/yontanbe/mishak-haotiyot.git
cd mishak-haotiyot
npm run build     # בונה את רשימת קטעי השמע ובודק שכל התמונות והקולות קיימים
npm run serve     # שרת מקומי
```
ואז לפתוח http://localhost:8080 . להוספת כפתור דילוג בין שלבים: http://localhost:8080/?dev=1

אין שלב קומפילציה: המשחק הוא HTML, CSS ו-JavaScript רגילים, כך שאפשר להעלות את התיקייה כמו שהיא לכל שרת סטטי (Netlify, Cloudflare Pages, Vercel ועוד).

## לשנות תוכן, קול ואיורים
1. מילים, חברים והוראות (עם ניקוד): js/data.js
2. אחרי שינוי טקסט: npm run clips מעדכן את audio/clips.json, ואז tools/gen_audio.py יוצר את הקטעים החדשים עם Gemini TTS (רץ בסביבת העבודה של Composio).
3. איורים: img/lula (שש תנוחות של לולה), img/friends (החברים), img/regions (רקעים). מקור הגיליונות בתיקייה art.
4. npm run check מראה אם חסר משהו.
