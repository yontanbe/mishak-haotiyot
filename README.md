# משחק האותיות א-ב 🎒

מסע קסום עם לוּלָה הַמְּגַלָּה ללימוד אותיות ומילים, לגן חובה ולכיתה א.

רוח שובבה העיפה את כל האותיות מהתיק של לולה. יוצאים איתה דרך יער, חווה, חוף, מדבר, הרים, טירה בעננים ועמק הסופיות,
פוגשים 27 חברים, ובכל תחנה מחזירים אות אחת הביתה דרך 19 שלבים: סיפור, הכרות עם האות, הברות, ציור באצבע,
שש מילים חדשות, בועות, בחירת תמונות, האזנה, מחבואים, זיכרון, אות חסרה, כן או לא, מסיבת מילים וחגיגה.

- 22 אותיות ו-5 אותיות סופיות
- כל הטקסטים עם ניקוד מלא
- קריינות בעברית שנוצרה עם Gemini TTS לפי הניקוד (616 קטעים), עם גיבוי לדיבור של הדפדפן
- איורים בסגנון תלת ממדי רך שנוצרו עם Gemini
- עובד בטלפון, בטאבלט ובמחשב, בלי התקנה ובלי שרת

## הפעלה
```
npm run serve
```
ואז לפתוח http://localhost:8080 . להוספת כפתור דילוג בין שלבים: http://localhost:8080/?dev=1

## התוכנית המלאה
ראו [docs/PLAN.md](docs/PLAN.md): הדמות, המסע, 19 השלבים, המחקר שעליו זה מבוסס, ושלבים הבאים.

## עדכון תוכן וקול
1. עורכים את js/data.js (מילים, חברים, הוראות, עם ניקוד).
2. מריצים npm run clips כדי לעדכן את audio/clips.json.
3. מריצים את tools/gen_audio.py בסביבת העבודה של Composio כדי ליצור את הקטעים החדשים.
